# OSMINOG 4.0.19 — Инструменты и свойства

Вернулись настройки холста: точки, плитка, комбинированная сетка, шаг, цвет сетки и фон для светлой/тёмной темы. Белый фон больше не подменяется серым.

Выбор фигуры перенесён в меню у иконки инструмента. Компактные плоские секции свойств, SVG-иконки, HEX-поля, проценты прозрачности, градиенты, отдельные углы и видимость заливки/обводки. У рисунков доступны цвет и толщина штриха. Клавиатурная навигация меню больше не двигает объекты.

Сохранены скрытие панели, обработка фото прямо на холсте, автосохранение, слои и индивидуальный чат. Иконки Lucide включены локально с лицензией.
