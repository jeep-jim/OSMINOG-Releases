# OSMINOG Chrome 4.0.36

OSMINOG 4.0.36 — кандидат восстановления производительности. Встроенный универсальный браузер удалён из Chrome-расширения полностью: browser app, web-stage/popup, URL-навигация, редактор веб-страниц, браузерные AI-команды и связанный runtime/UI. Подключения AI-провайдеров и отдельные управляемые сессии авторизации сохранены. Старые карточки ссылок остаются обычными безопасными внешними ссылками.

Исправлена подтверждённая алгоритмическая регрессия счётчиков папок: вместо повторного полного прохода по объектам для каждой видимой папки используется один проход по объектам и папкам (O(N+F) вместо O(N×F)). Добавлен regression test с 60 папками и 2 400 объектами. Данные проектов, ключ расширения, Owner Access, чат, папки, файлы, импорт и инструменты изображений сохранены.

Проверки итогового исходного коммита: Chrome runtime/build, workspace/diagnostics, browser retirement, graphics и retained compatibility — все завершились успешно. Полный пакет создан из проверенного CI-артефакта; ZIP SHA-256 3c71da62b7556d6cbf281441f311494957ae14108f46e9c2baa61c79a138da9b, размер 9 526 265 байт.

4.0.20 — контрольная точка, которую владелец назвал последней стабильной. Автоматические тесты подтверждают исправление конкретного квадратичного прохода и отсутствие регрессий в проверенных сценариях, но не являются измерением CPU/RAM/p95 на компьютере владельца. Поэтому runtimeVerified остаётся false до проверки владельцем после обновления через существующую кнопку. Это dev-кандидат, а не заявление о завершённой пользовательской приёмке.
