# OSMINOG Chrome 3.17.0 — GENERATIVE APP RUNTIME

This release removes hard-coded stopwatch, calendar and player templates. Every app/widget is generated by the connected AI from the user's current request and preferences.

OSMINOG owns the runtime: install, launch verification, transactional update/rollback, focus of an existing app for follow-up edits, selected canvas assets, screenshot/capture APIs, storage, browser/network access and binary JS/WASM fetch where permitted.

Compact widgets auto-size to natural content. Manual resize scales the application proportionally rather than clipping an iframe inside an outer container. Visible controls are audited for interaction handlers before an app is accepted as ready.

Emulator support is a capability, not a claim that every ROM/APK executes automatically. A compatible browser JS/WASM core is still required for the relevant format.
