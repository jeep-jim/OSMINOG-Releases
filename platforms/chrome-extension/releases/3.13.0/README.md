# OSMINOG Chrome 3.13.0 — APPLICATION WORKSPACE

This release rebuilds OSMINOG as a coherent application workspace instead of a collection of unrelated canvas tools.

- The bottom dock now contains eight permanent applications: OSMINOG AI, Graphics, Text, Browser, Files, Modules, Team and Development.
- Application icons live outside the zoomable canvas, keep one Nano Banana-compatible size and share the same hover and restore behavior.
- Every managed window uses one header shelf, opens above existing windows, can be moved and resized, and returns to the dock when minimized.
- System windows no longer expose meaningless node controls; object-capable windows keep a dedicated focus/node action.
- Graphics consolidates selection, pen, vector, shapes and connections; completing a pencil stroke immediately returns to selection.
- Connections use a two-click flow and can start from grouped objects; nodes remain editable as canvas objects.
- Text creation is simplified and formatting moves to the right-side properties surface.
- Module Store uses a resizable split view, removes duplicated open/desktop actions and protects system modules from deletion.
- Extension Studio supports PNG, WebP, SVG and JPEG logos and no longer wraps extensions in a redundant opaque container.
- OSMINOG AI stays pinned to the latest message and treats the provider as a provider, not as the application identity.
- Internet image requests now require the live `asset_create` operation and a real returned canvas object ID; transparent assets stay transparent and are placed as files, not browser cards or iframes.
- Access and Poseidon/source permissions are consolidated into one permissions center.
- Self-observing render loops remain removed for local responsiveness.
