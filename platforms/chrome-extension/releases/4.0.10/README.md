# OSMINOG 4.0.10 — изображения, вкладки ИИ и логотип

Обновление через существующую кнопку в шапке OSMINOG. Ручная загрузка и переустановка не требуются.

- Изображения на холсте без скругления и крестика удаления; Delete и отмена сохранены.
- Ровные симметричные осьминожки во вкладках чата.
- Логотип-глаз из Windows вместо красной точки.
- Кнопка слоёв первой слева.
- Добавление ИИ через + создаёт видимую отдельную вкладку; переписки и активная вкладка сохраняются после перезагрузки.

Проверки Chrome и совместимости Windows прошли. Ответы ИИ проверялись на тестовых провайдерах, не на реальных аккаунтах владельца. Ключ расширения, разрешения, формат проектов и механизм обновления сохранены.
