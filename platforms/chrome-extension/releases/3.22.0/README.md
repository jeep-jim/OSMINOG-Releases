# OSMINOG 3.22.0

Исправлены повторяющиеся блоки контекста и автоматические скриншоты при подключенном чате. Полное содержимое холста запрашивается отдельно. Исправлен импорт изображений из повторно используемого контейнера ответа; временные ошибки повторяются до трёх попыток. Все CI-проверки прошли, включая браузерные сценарии пяти провайдеров. Совместимость с авторизованными сервисами изображений в живом чате отдельно не подтверждена. Это ремонтный релиз внешнего AI-моста; пять новых рабочих сценариев остаются в roadmap.

Обновление: кнопка версии → обновить. Постоянный ключ расширения сохранён.
