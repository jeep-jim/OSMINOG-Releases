# OSMINOG Chrome 3.20.3 — восстановление холста и подключения

Исправлены цикл графического инспектора, зависание при выборе изображения/текста, двойной импорт внешних файлов и блокировка внутренних переносов. Объект из папки сохраняет ID; реальный файл читается целиком. В «Доступе» возвращена форма «Текущий ChatGPT → роль → Подключить». Исправлен null/undefined на повторном запросе Team.

Интерфейс и изображения сохранены от точного пакета 3.20.1. Исходники: [PR #6](https://github.com/jeep-jim/OSMINOG/pull/6), commit `eb07c8be9897aedc3b6e8ae2985832ee50dd7b6e`. Все 92 файла ZIP совпадают с этим source commit.

Проверено в Chromium 149: внешний повторный drop, внутренний перенос изображения без дубля, перенос 260001 байт текста без обрезки, bold/italic и сохранение, форма подключения и выбранная роль. Chrome API, file handle и ответ провайдера в тестах подставные. `runtimeVerified=false`: живой ChatGPT, установка Windows Dev Hub и профиль владельца ещё не проверены.

Проверка после обновления: внешний файл → объект из внутренней папки → текст с оформлением → «Доступ / Текущий ChatGPT / Подключить» → запрос о холсте.
