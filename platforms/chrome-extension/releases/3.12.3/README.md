# OSMINOG Chrome 3.12.3 — UNIFIED WORKSPACE

This release repairs the OSMINOG execution path and gives the workspace one consistent desktop/window model.

- Product and source commands from the permanent main chat route directly to the private jeep-jim/OSMINOG source via owner-confirmed GitHub tools.
- A selected local source folder is no longer required for GitHub edits.
- Machine-only patch/request JSON is hidden from visible chat messages.
- All managed windows share deterministic front focus, move, resize, minimize, restore and close behavior.
- Minimized windows remain visible in the top tray.
- Module Store uses a clickable list with a right-side details/actions pane instead of duplicate buttons on every card.
- Custom modules can be deleted; system modules are protected; removing a desktop shortcut keeps the module installed.
- Widgets render without a redundant dark host container.
- Desktop icons and hover interactions use one visual language.
- Small clocks, calculators, timers and similar utilities default to compact widget mode.
- Web results can be saved as embedded canvas files; PNG, WebP and SVG transparency is preserved.
- Vector creation now specifies cubic Bézier handles and rejects primitive placeholder illustrations.
