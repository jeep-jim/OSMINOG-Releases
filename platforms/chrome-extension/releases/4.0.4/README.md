# OSMINOG 4.0.4 · Доски и контекст

Основной сценарий: хранить материалы на бесконечных досках, редактировать их и передавать контекст внешнему ChatGPT.

- Сверху отдельное меню «Сайты и макеты»: сохранённые приложения, редактируемые копии и редактор по адресу сайта. Закрытие окна не удаляет материал.
- HTML/CSS редактируется прямо в окне созданного сайта. Для визуальной правки открывается отдельная сохраняемая копия; исходное приложение сохраняется.
- Исправлены приветствие, раскладка текста и крестик закрытия.
- Добавлена заметная кнопка «Для ChatGPT», передача карты объектов и связей при сообщении в подключённом внешнем чате, ручное копирование/скачивание контекста текущей доски.
- Конфликт с синхронизацией внутреннего чата теперь сообщает ошибку вместо ложного подключения. Для внешнего контекста нужна вкладка без этой привязки.
- Генерация с API и другие ИИ перенесены в дополнительные возможности. Ключ не требуется для досок и передачи контекста.
- Обновление по кнопке сохранено.

Все автоматические и браузерные проверки пройдены. Живая передача контекста в чат пользователя не подтверждена. Экспорт Markdown — снимок текстового контекста; изображения прикрепляются отдельно. Редактор сайтов изменяет локальную копию; защищённые/динамические сайты могут не отдавать полную вёрстку. Это публикация GitHub/dev-канала, не публикация в магазинах Chrome или ChatGPT.
