# OSMINOG Chrome 4.0.31

OSMINOG 4.0.31. Восстановлен штатный Browser App вместо упрощённой iframe-панели. Компактные вкладки с плюсом после вкладок, короткая адресная строка. Браузер пристыкован к рабочей области, разделяется со столом перетаскиваемым разделителем и занимает всю ширину после закрытия чата. ChatGPT и Figma открываются через управляемые вкладки Chrome того же профиля, с VPN и расширениями; ограничения CSP/X-Frame-Options не обходятся. Добавлен перенос выбранных изображений, видео, аудио и CSS background-image на стол через Project API из редактируемой копии страницы. Защищённые вкладки не имитируют доступ к DOM. Authenticator сохранён побайтово; ключ расширения прежний.
