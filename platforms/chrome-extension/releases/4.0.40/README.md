# OSMINOG Chrome 4.0.40

OSMINOG 4.0.40 — снижение нагрузки боковых панелей с сохранением текущего интерфейса и инструментов.

Восстановлена настройка миниатюр из Chrome 4.0.20: список сохранённых материалов теперь тоже учитывает «Мини-превью слоёв». Закрытая панель не строит список при первом рендере; оригиналы изображений загружаются только у видимых строк, ссылки и наблюдатели освобождаются при закрытии или перестроении.

Изменение ширины меню сохраняет только два размера, без полной записи проектов, резервных копий и ревизий. Размеры восстанавливаются после асинхронной загрузки проекта. Исправлена гонка фокуса подтверждения удаления и очистка обработчика при Escape.

Сравнение выполнено с 3cdc60a, содержащим Chrome manifest 4.0.20. Ранее указанный e0e9917 содержит manifest Chrome 4.0.9. Отдельный опубликованный архив Chrome 4.0.20 в текущем реестре не найден.

Все пять проверок итогового коммита d8389dec31493a4bf00c9581a68760848cb32383 завершились успешно. Проверены настоящий буфер, восстановление данных, установка/перезапуск расширения, графика, документы, фото, чат и сценарий 80 изображений 3840×2160 в архивной панели. ZIP из успешного CI сверён побайтно с исходниками и закреплёнными OCR-ресурсами: 150 файлов, 9332590 байт, SHA-256 35713f54ee2623132fd4b2bcbb180109b737abd84bd48443de1958b14edfeb56. Обновлятор, ключ расширения и Owner Authenticator не изменены.
