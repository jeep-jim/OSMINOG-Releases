# OSMINOG Chrome 3.13.3 — UNIFIED BROWSER AND ACCESS

- Website layout editing now stays inside the new Browser application.
- Browser tabs, editable snapshots, element move/resize, text, color, opacity, HTML and a local inspector live in one window.
- AI services can open in internal OSMINOG browser tabs.
- AI sessions, canvas access, Poseidon, source folder, GitHub and project sharing are unified in one control center.
- Legacy access/connection routes no longer open duplicate windows.
- Minimized system windows no longer create tiny raw-letter icons on the right side of the dock.

Protected login services may require a linked Chrome tab because their CSP/X-Frame-Options forbid embedding; connection and synchronization remain managed from OSMINOG's unified center.
