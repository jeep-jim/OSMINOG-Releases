# OSMINOG Chrome 5.0.0

OSMINOG Light 5.0.0: отдельный лёгкий интерфейс хранения текста, скриншотов и медиа; старый редактор и тяжёлые инструменты исключены из пакета. Только GPT/DeepSeek. Ограниченный видимый холст, готовые миниатюры, отдельные оригиналы и сохранение одной записи при перемещении. Free: 100 изображений в месяц, 3 стола. Pro и потоковый ZIP подготовлены, оплата не подключена. Пройдены native Chromium Windows/Linux: 3000 изображений, буфер, текст, перезапуск обновления; это не проверка личного компьютера владельца. Старые данные не удаляются: отдельные записи IndexedDB переносятся вручную, общий снимок прежнего холста пока не импортируется и даже не читается для измерения размера.
