# OSMINOG Chrome 3.18.0 — PRODUCT CORE RECOVERY

Restores the simple product model of the proven 3.11 generation while retaining the 3.17 generative application runtime.

- top bar has explicit **AI** and **Poseidon** states;
- normal canvas/files/apps/graphics/web/project capabilities need no permission toggles;
- **Access** is only human canvas sharing and view/comment/edit roles;
- user GitHub project storage is separate from owner-only Poseidon;
- Google Drive is surfaced again through the existing OAuth/Drive API;
- arbitrary web services can be added by URL and use their real favicon;
- stale test modules incorrectly marked system become deletable;
- header/action alignment and chat nested surfaces are simplified;
- 3.17 Generative App Runtime remains intact.
