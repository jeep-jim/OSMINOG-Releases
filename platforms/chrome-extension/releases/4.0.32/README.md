# OSMINOG Chrome 4.0.32

OSMINOG 4.0.32 — экспериментальное магнитное окно. Обновление расширения поверх 4.0.31; отдельное Windows-приложение не изменяется.
Живые страницы открываются в настоящих окнах Chrome того же профиля, а не в iframe. Выбранное окно подгоняется к рамке браузерной области OSMINOG. Каждая логическая вкладка имеет своё окно (до восьми); невыбранные сворачиваются, состояние страниц при переключении сохраняется.
Изменение размера стола и чата подстраивает окно, не забирая фокус клавиатуры. Добавлена кнопка «Вернуть окно сайта к рамке»; режим «только стол» скрывает и браузерную область, и окна сайтов.
Важно: это отдельные окна ОС, не полностью встроенный браузер. Постоянного always-on-top нет; при работе со столом, чатом или другими приложениями окно сайта может оказаться позади. Кнопка возврата поднимает его явно. Окна входа и страницы, открываемые сайтом в новом окне, остаются отдельными — их POST-формы и контекст не пересоздаются.
Сохранён перенос изображения из редактируемой копии сайта на стол; чтение копии требует разрешения доступа к домену.
Полная Chrome-сборка и четыре дополнительные проверки прошли. На контролируемых страницах проверены запрет встраивания, интерактивность настоящей страницы, переключение без перезагрузки, сохранение POST-окна, геометрия, фокус, скрытие, перенос изображения и защита чужих вкладок. Живые аккаунты Figma/Google/ChatGPT и конкретный Windows-компьютер владельца отдельно не тестировались.
Authenticator и прежний background.js побайтово совпадают с 4.0.31; ключ расширения и постоянные разрешения сохранены. Пакет передаётся через штатную кнопку обновления, без ручной распаковки.
