# OSMINOG 4.0.8 — чистый холст и прямой ввод текста

Обновление через существующую кнопку: нажмите версию в шапке OSMINOG → «Обновить сейчас». Вручную скачивать архив, распаковывать файлы или удалять расширение не требуется.

- Ctrl + \ скрывает интерфейс; повторное нажатие возвращает панели.
- T → клик по доске → сразу ввод текста; настройки справа.
- Нижняя плавающая панель рисования, SVG-иконки, точки активного инструмента.
- Масштаб 0,5–800%, расширенная плоскость доски.
- Ластик штрихов, отмена и повтор.

Формат досок, идентификатор расширения, разрешения и связь с ИИ сохранены. Проверенная сборка: 23 сценария Canvas UX и прежние регрессии в GitHub Actions.
