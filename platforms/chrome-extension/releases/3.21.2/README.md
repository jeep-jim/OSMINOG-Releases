# OSMINOG 3.21.2

OSMINOG 3.21.2: перенос в папки холста убирает объекты со стола без дублей, очищает выделение и скрывает связи. Содержимое папок не удаляется вместе с оставшимися объектами стола. Проверены восемь типов объектов, перенос между папками, возврат, Undo/Redo и сохранение после перезагрузки. Для генерации добавлены отдельный запрос с референсом, обработка изображений от инструмента, файловых указателей и SSE-изменений; сохраняется конкретная ошибка получения файла. Все 3 CI прошли. Живая генерация в установленном Chrome пользователя не проверена; runtimeVerified=false.
