# OSMINOG Chrome 4.0.39

OSMINOG 4.0.39 — возврат прежнего приложения с исправлениями нагрузки.

Возвращены интерфейс и набор инструментов Chrome 4.0.37: прежний холст, столы, папки, слои, файлы, связи, чат справа, доступ, редакторы фотографий и векторов, документы, экспорт, снимки экрана, поиск и OCR. Упрощённый редактор 4.0.38 больше не используется. Номер 4.0.39 нужен для установки возврата поверх 4.0.38.

Шапка сохраняет положение, боковые панели открываются под ней. Холст создаёт элементы для видимой области и сохраняет неизменившиеся изображения и текстовые узлы. Полная модель остаётся доступна поиску, экспорту и инструментам. Неизменившиеся подписи и счётчики папок не переписываются при каждом обновлении.

Перемещение объектов, панорамирование, масштабирование и переключение существующих столов сохраняют небольшие журналы вместо повторной записи всей медиатеки. Полное сохранение сохраняет правки, пришедшие во время записи; выбор стола восстанавливается при перезапуске, переводе часов назад и смешении основного снимка с более новой папкой. Для переключения столов в нативной проверке записывались 234–244 байта метаданных без основной рабочей области, резервной копии и ревизии.

Фоновый сбор буфера сохраняет бинарные данные в отдельной очереди IndexedDB и обрабатывает файлы последовательно. Неизменившиеся файлы не проходят повторное полное хеширование; подтверждение удаления из очереди приходит после надёжной записи в проект. Проверены настоящий текст и PNG при закрытом редакторе, точные пиксели, отсутствие повторов и пауза сбора.

Материалы и переписка из 4.0.38 переносятся в восстановленный интерфейс. Исходные базы остаются нетронутыми, а изменяемые прежние записи архивируются до переноса. Сохраняются удаления, неизвестные свойства, файлы и исходный код. Новые текстовые карточки используют читаемый цвет текущей темы.

Нагрузочная модель: 2 400 объектов, 60 папок и 1 200 разных изображений 512×384. В основном сценарии взаимодействия измерено 189 интервалов кадров: p95 16,8 мс, максимум 133,3 мс, LongTasks 0. Шапка проверена при ширине 1440 и 1024. Новые заметки проверены в светлой и тёмной темах.

Если старая кнопка обновления приводила к зависанию: закройте вкладки OSMINOG, откройте OSMINOG-Update-Recovery.html из этого выпуска в Chrome, выберите папку установленного расширения с manifest.json и нажмите «Установить исправление». Затем откройте значок OSMINOG и нажмите «Завершить обновление». Если Chrome показывает старое меню, используйте круговую стрелку на карточке OSMINOG в chrome://extensions.
