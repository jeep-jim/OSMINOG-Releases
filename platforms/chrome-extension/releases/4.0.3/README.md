# OSMINOG 4.0.3 · Генерация изображений

- Возвращены графический редактор, анимация, команда ИИ, вкладки агентов и выбор провайдера. Инструменты доступны в верхнем меню.
- Создание сайта/вёрстки больше не отправляется в редактирование исходников с Owner Unlock. Защита изменений самого продукта сохранена.
- Поиск фото по командам «выкинь/закинь на холст» запускает поиск и импорт без подключения текстовой модели.
- Добавлен OpenAI Images API: Flare/Sunburst, высокое качество по умолчанию, выбор размера и качества, до четырёх референсов, исходный PNG на доске. Запуск обычной фразой из внутреннего чата.
- Подключённый ChatGPT остаётся источником по умолчанию. API-режим включается отдельно, требует собственного ключа и оплачивается в API-проекте. Ключ хранится только до перезагрузки страницы.
- Отмена ожидания и скачивание последнего результата. Нет автоматических повторов платных запросов.
- Обновление по кнопке и идентификатор расширения сохранены.

Регрессионные и браузерные проверки пройдены, включая полный путь чат → тестовый API → реальный объект на доске. Живая платная генерация и пользовательские сессии не проверены. 3D-изображение не является моделью с сеткой и ригом.
