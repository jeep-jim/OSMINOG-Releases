# OSMINOG 4.0.5 · Исправление команд с фото

- «Выкинь фото верблюда на оску» и «закинь фото орла» запускают прямой поиск и добавление: распознавание больше не зависит от правильного написания слова «доска».
- Исправлена проверка неоднозначности: часть слова, например «или» внутри «лилии», больше не отключает прямой поиск. Вводное «вот» допустимо.
- Команды добавления веб-фото обходят командный режим и не требуют подключения текстового ИИ. Отрицательные команды не выполняются автоматически.
- Добавлена браузерная проверка точной фразы пользователя: тестовый ответ поиска, настоящее создание изображения на доске, текстовый провайдер недоступен.

Полный CI пройден. Живой поиск и релевантность результатов на устройстве пользователя этой проверкой не подтверждаются. Интерфейс и механизм обновления не изменены.
