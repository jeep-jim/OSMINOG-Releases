# OSMINOG Chrome 3.13.1 — ART ICONS AND READER SCROLL

This UX hotfix keeps reading under the owner's control and replaces generic colored icon containers with real application artwork.

- Opening OSMINOG AI or changing a conversation reveals its latest message once.
- Incoming AI messages, progress steps, team responses and final results preserve the reader's current scroll position.
- Sending a user message reveals that message, then returns scroll control to the reader.
- The eight permanent dock applications no longer use colored rounded-square icon containers.
- Every core application now has independent multicolor SVG artwork with highlights, depth and a common hover treatment.
- Files uses the requested dimensional yellow folder artwork.
- Managed application headers reuse the same artwork without adding another colored container.
