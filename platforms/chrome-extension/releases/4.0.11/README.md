# OSMINOG 4.0.11 — GitHub Workspace

Обновление через кнопку в OSMINOG.

- Вход владельца заново проверяет GitHub и сохраняет подтверждение; переподключение доступно в том же окне, Google Authenticator сохраняется.
- Большие исходники и дерево репозитория читаются по частям без незаметной потери хвоста.
- Точечные правки сверяют исходный SHA; устаревшая версия не перезаписывается. Записанный коммит проверяется повторным чтением.
- Агент начинает разработку с GitHub без обязательной локальной папки; доступны ветки, PR и статусы Actions.
- Обсуждение возможности разработки не запускает обязательную мутацию. Запуск workflow не выдаётся за завершённую публикацию.
- Неверная папка обновления сбрасывается для повторного выбора.

Проверки: GitHub gateway, повторный вход и переподключение, отказ при недоступном GitHub, общие сценарии холста и чатов прошли. Тесты gateway используют тестовые ответы GitHub; реальный установленный токен владельца и внутренний чат необходимо проверить после обновления. Обновление не выдаёт токену новые права.
