# OSMINOG Chrome 4.0.34

OSMINOG 4.0.34 — обновление рабочего пространства в стиле Figma. Обновление расширения поверх 4.0.33; отдельное Windows-приложение не изменяется.
Правая панель поиска и сохранённых материалов открывается отдельной колонкой справа от чата, не перекрывая его.
У объектов четыре угловых маркера изменения размера с постоянным экранным размером при zoom; боковые маркеры убраны.
Ctrl/Command фиксирует квадратные пропорции при создании фигур и сохраняет исходное соотношение сторон при изменении размера выделенного объекта.
Числовые свойства можно менять перетаскиванием мыши по горизонтали; обычный ввод сохранён.
Галерея файлов использует три столбца с крупными превью. Одиночный клик открывает предпросмотр с действиями «На холст», «Скачать», «Копировать», «Свойства» и «Открыть файл» там, где поддерживается.
Кнопка «Экспорт» сохранена и открывает экспорт выделенных объектов; при пустом выделении отключена.
Дополнительно исправлена обработка стрелок в диалоге подтверждения удаления: клавиатурное переключение фокуса и подтверждение проверены регрессионными тестами.
Все обязательные CI-проверки прошли, включая полную диагностику рабочего места, корзину/входящие, документы и совместимость. Архив проверен на целостность, версию манифеста и сохранение постоянного ключа расширения.
Authenticator, manifest key, постоянные разрешения и данные проектов сохранены. Отдельное Windows-приложение не менялось.
