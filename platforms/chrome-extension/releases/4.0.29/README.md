# OSMINOG Chrome 4.0.29

OSMINOG 4.0.29 поверх единой 4.0.28.
Шапки стола и чата выровнены по одной высоте; светлая тема получила серую границу и разделитель.
Удалено отдельное всплывающее окно «Подключения ИИ»: настройки провайдера остаются в чате, доступ владельца сохранён.
Глобус открывает веб-область внутри рабочего пространства; монитор включает стол рядом со страницей. Ширина меняется разделителем; закрытие чата освобождает всю ширину. Добавлены исходный домен, адрес и плюс для новой ссылки.
Обычные ссылки больше не направляются в скрытое окно служебных ИИ-сессий. Ссылки хранятся отдельно по проектам и не загружаются при восстановлении без явного открытия.
Важно: в Chrome это изолированный веб-просмотр, а не нативный браузер. Ограничения X-Frame-Options/CSP сохраняются; поддержка VK/Figma внутри расширения не подтверждена. Чтение DOM и действия ИИ в этом просмотре не заявляются. Для запрещающего встраивание сайта есть явная кнопка ↗, открывающая обычную активную вкладку только по нажатию. Нативный Windows-браузер не заменён.
Authenticator побайтово совпадает с исправленной 4.0.28; ключ расширения сохранён. Проверены реальные взаимодействия во фрейме расширения, отсутствие скрытых окон, геометрия, изоляция проектов и сохранение запрета встраивания. Обновление штатной кнопкой, без ручной распаковки. Проверка на личном устройстве владельца не заявляется.
