# OSMINOG 4.0.9 — инструменты ИИ, сессии устройств и групповой чат

Обновление через существующую кнопку: версия в шапке OSMINOG → «Обновить сейчас». Ручная загрузка архива и переустановка не требуются.

- Внутренний исполнитель снова получает актуальный контекст доски и действующие команды, отдельно от явной синхронизации с личным чатом.
- Устаревшие номера служебных вкладок не используются в другой сессии браузера. Закрытая служебная вкладка восстанавливается до отправки; неоднозначно отправленный запрос автоматически не дублируется.
- Доступ к исходникам OSMINOG сохранён за «Посейдоном», проверкой владельца и подтверждением. Рабочие инструменты доски не требуют прав владельца продукта.
- Восстановлен групповой режим: история команды привязана к проекту, результаты и изображения возвращаются агентам без подмешивания чужих личных диалогов.
- Убрана дублирующая кнопка «Для ChatGPT»; внешний мост и права доступны в «Доступ».
- Нижние меню открываются по наведению. Наведение не переключает активный инструмент; обычный клик T по-прежнему включает ввод текста на доске.
- Предложенная, применённая, отклонённая и отменённая правки имеют разные подтверждённые статусы. Ошибки больше не оформляются как успешное подключение.

Проверено: 14 сценариев сессий, 14 браузерных сценариев исполнителя, отдельная проверка результатов правок и прежние проверки доски/чата/документов. Все три PR-процесса GitHub Actions прошли. Проверки используют тестовые ответы провайдеров, не реальные авторизованные профили владельца.

На каждом компьютере требуется собственный вход в выбранный ИИ. Обновление не переносит cookies и не является облачной синхронизацией досок. Формат проектов, ключ и разрешения расширения сохранены.
