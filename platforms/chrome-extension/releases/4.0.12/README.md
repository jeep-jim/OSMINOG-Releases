# OSMINOG 4.0.12 — выполнение задач с исходниками

Обновление через существующую кнопку OSMINOG.

Исправлено: фраза «основную ветку и интерфейс пока не меняй» больше не переводит всё задание создать отдельную ветку и коммит в обычную беседу. Ограничение остаётся в запросе, а выполнение source-задачи и продолжение после ответа без действий включены.

Проверен точный текст пользователя через кнопку отправки главного чата с тестовым провайдером: GitHub status, дерево, manifest, ветка, коммит, повторное чтение; реальные вызовы host bridge и возврат результатов модели, без изменений холста. Пустой ответ GitHub host теперь возвращается как явная ошибка. Создание одной ветки не считается завершением source-задачи в дополнительных вкладках. Старое название «Посейдон» в окне доступа заменено на «Исходники OSMINOG · доступ владельца».

Все CI проверки прошли. Ответы GitHub/провайдера в новом тесте синтетические; результат реального внутреннего чата на устройстве владельца необходимо подтвердить после обновления.
