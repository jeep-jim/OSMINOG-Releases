# OSMINOG Chrome 4.0.33

OSMINOG 4.0.33 — компактная рамка браузера и более устойчивое плавающее окно. Обновление расширения поверх 4.0.32; отдельное Windows-приложение не изменяется.
Внутренняя верхняя плашка OSMINOG Browser App удалена. Убраны неработающие кнопки «Открыть» и «Редактировать вёрстку»; адрес открывается клавишей Enter, вкладки и навигация остаются.
Для системной строки заголовка Chrome зарезервирована отдельная полоса внутри рамки. Геометрия popup включает эту полосу, чтобы системные кнопки окна помещались в контур, а содержимое сайта начиналось у рабочей области.
Переключение вкладки основного Chrome или сворачивание родительского окна больше не отправляет popup в minimized автоматически. При этом Chrome/ОС всё ещё могут расположить отдельное окно позади родительского; постоянный always-on-top не обещается.
Переключение логических вкладок сайта по-прежнему сворачивает невыбранное окно и сохраняет страницу. Сохранены окна авторизации/POST, перенос медиа через поддерживаемую редактируемую копию, Authenticator, ключ расширения и существующие разрешения.
Полная Chrome-сборка, реальные browser-stage проверки, workdesk/document, project-trash и compatibility workflows прошли. Работа живых аккаунтов и конкретного Windows-компьютера владельца отдельно не подтверждалась.
