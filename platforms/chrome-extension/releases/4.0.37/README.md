# OSMINOG Chrome 4.0.37

OSMINOG 4.0.37 — переработка обновления после сообщения владельца о трёх закрытиях браузера при попытке установить 4.0.36.

Updater 2.0.0 заменяет полное рекурсивное копирование папки в память обработкой ограниченного пакета и резервными копиями только заменяемых программных файлов. Добавлены проверка ZIP и каждого записанного файла, журнал восстановления, откат при ошибке и защита от одновременной установки. manifest.json записывается последним.

Перед перезапуском расширения создаётся обычная временная вкладка. Подтверждение запуска принимается только от редактора целевой версии; затем убирается только эта неизменённая временная вкладка. Обычная кнопка обновления сохраняет стол перед установкой.

Для первого перехода со старого обновлятора опубликован OSMINOG-Update-Recovery.html из того же проверенного CI-артефакта. Старую кнопку повторять не требуется: открыть помощник в Chrome, выбрать папку установленного OSMINOG и нажать «Установить исправление». После завершения открыть значок расширения и нажать «Завершить обновление». Ручное скачивание и распаковка ZIP не нужны. Помощник сам не перезапускает расширение. Если Chrome показывает старое меню, круговая стрелка на карточке OSMINOG в chrome://extensions загружает новые файлы без удаления расширения.

CI проверяет реальные файловые операции и перезапуски в Chromium: обычное обновление, единственное оставшееся окно расширения, сохранение проекта и посторонней вкладки, установка через интерфейс помощника и завершение через новое меню. Отдельно проверяется загрузка опубликованного ZIP из file:// через настоящий сетевой запрос. В тесте выбора папки используется настоящий FileSystemDirectoryHandle с подготовленным разрешением; системный диалог выбора папки не автоматизируется.

Постоянный ключ расширения и байты Owner Authenticator сохранены. Встроенный браузер остаётся удалённым. ciVerified=true; runtimeVerified=false: CI не является наблюдением за Windows-профилем владельца. Точная причина трёх исходных закрытий на его компьютере не установлена, и пользовательская проверка этой версии не заявляется.
