# OSMINOG Chrome 4.0.28

Единое обновление OSMINOG 4.0.28 поверх 4.0.27, без отката на 4.0.25.1 и без отдельной промежуточной установки. Объединены исправление Authenticator (ключ незавершённой настройки сохраняется, готовая привязка не сбрасывается), корзина проектов с подтверждением удаления и восстановлением в течение семи дней, окончательное удаление из корзины, зелёные «Входящие» по умолчанию, счётчик сегодняшних сохранений в окне расширения и переход оттуда на стол, увеличенные подписи и скрытие служебной папки хранилища с холста. Удалены старый магазин модулей и устаревшая плитка выбора ИИ; рабочий чат, подключение провайдеров и доступ владельца сохранены. Сохранены ограничения фоновой обработки, раздельная запись новых материалов и восстановление редактора после обновления. Проверены настоящий буфер обмена, сохранение и перезапуск браузера; файл авторизации побайтово совпадает с отдельным исправлением. Ключ расширения сохранён. Установка штатной кнопкой «Обновить»; ручная распаковка и переустановка не требуются. Проверка на личном компьютере владельца отдельно не заявляется.
