# Mouse Browser 6.0.20 — мордочка, локальный архив и аккуратная история

Вместо мыши с хвостом используется исходная мордочка владельца, включая иконку приложения/Dock и окно обновления. В инкогнито — эта же мордочка в очках и ровный пиксельный заголовок.

Окно обновления можно свернуть кнопкой рядом с закрытием. Скачивание продолжается, процент отображается в нижней кнопке версии; повторное нажатие возвращает окно. Установка остаётся отдельным действием пользователя.

Кнопки панели ИИ сделаны квадратными со скруглением; круглые кнопки основных окон сохранены. Скругления внутренних стыков окон увеличены до12px; скорректирована отрисовка углов нативных страниц. Размеры обычной норки сохранены.

В плитках загруженных изображений отображаются миниатюры. Checkbox выровнены. В библиотеке появился раздел «Скриншоты» с предпросмотром локальных изображений и текста.

Автосбор выключен по умолчанию. После явного включения и подтверждения новые изображения/текст из системного буфера и новые изображения из выбранной папки скриншотов копируются в `~/Mouse Captures`. Работает только при запущенном браузере; нет фонового демона, записи экрана, перехвата клавиш или передачи в сеть. Старый буфер и старые файлы автоматически не импортируются. В инкогнито и при блокировке сбор приостанавливается. Буфер может содержать секреты; распознаются не все. Локальные копии не зашифрованы, на macOS доступны владельцу учётной записи. Лимит1000копий/512МБ останавливает сбор. Удаление в этом разделе удаляет только созданные копии, не исходные файлы. Есть ручное добавление.

История больше не создаёт отдельную запись на каждое действие, изменение заголовка, якоря, фильтра или перезагрузку текущей страницы. Сохраняются отдельные посещённые страницы и маршруты. Технические страницы проверки доступа пропускаются. Повторы старой истории группируются при показе по странице и дню без автоматического удаления исходных записей; очистка остаётся явным действием.

Предварительный выпуск для macOS Apple Silicon (arm64). Подпись ad-hoc, без Developer ID и нотариализации Apple. Обновлять поверх установленного приложения, профиль не удалять. Windows-приложение этим выпуском не публикуется. АвтоЦена, DNS и другие проекты не изменены.
