# МАУС · Mouse Browser 6.0.14

Проект: **Mouse Browser**, домен **mouse.black**. Для Mac Apple Silicon, включая M1 Pro.

Вместо «+» новой вкладки — мышиная норка. Она остаётся рядом с последней вкладкой; нажатие открывает новую вкладку, сочетание ⌘T и доступное название сохранены. Мышь-маскот, очки и иконка Dock не перерисованы.

В шапке правого ИИ-чата вместо дублирующего «+» установлена кнопка ⤢, как у обычных окон. Добавление ИИ по ссылке остаётся в раскрывающемся списке сервисов. Повторное нажатие на ⤡ или Esc возвращает чат справа с прежней шириной и раскладкой остальных окон. Страница не перезагружается; её состояние и черновик сохраняются. При исходно полноэкранном браузере возврат к раскладке оставляет браузер полноэкранным.

Кнопка обновления получает постоянную зелёную рамку только после проверки более новой доступной версии. Рамка сохраняется при скачивании и после закрытия окна обновления. Оттенки отличаются для светлой и тёмной тем. Ошибка сети сама по себе рамку не включает; при подтверждении актуальной версии она исчезает. В обычном режиме запущенное приложение проверяет только метаданные при запуске и примерно каждые 15 минут. Скачивание и установка — только по нажатию пользователя; в инкогнито автоматической проверки нет.

Действующие Mac-файлы, имена внутренних интерфейсов и проверок переименованы в Mouse. About и описание используют mouse.black. Старые ключи профиля, идентификатор приложения, адреса ранее выпущенных установщиков и канала сохранены для совместимости с установленными версиями. Архивные записи, репозитории и файлы других платформ не удалялись. Это не регистрация домена и не изменение DNS/хостинга.

Обновление из 6.0.13: в обычном режиме «Обновить» → «Скачать обновление» → «Установить и перезапустить». Удалять приложение или профиль не нужно. Зелёный индикатор появится уже в установленной 6.0.14 и будет сигнализировать о следующих доступных выпусках; в старую 6.0.13 новый интерфейс до обновления не попадает.

Предварительная сборка с ad-hoc подписью, без Developer ID и нотариализации Apple. Защита macOS не отключается. Кошелёк остаётся экспериментальным, только Sepolia. Изменение названия не меняет эти ограничения.
