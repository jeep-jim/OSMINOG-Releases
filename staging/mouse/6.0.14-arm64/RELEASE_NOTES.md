# Mouse Browser 6.0.14 — ИИ на весь экран

В шапке правого ИИ-чата вместо дублирующего «+» установлена кнопка ⤢, как у обычных окон. Добавление ИИ по ссылке остаётся в раскрывающемся списке сервисов.

Нажатие разворачивает именно ИИ-чат на весь экран. Повторное нажатие на ⤡ или Esc возвращает чат на прежнее место справа с прежней шириной и раскладкой остальных окон. Страница чата не перезагружается; её текущее состояние и черновик сохраняются. Если браузер уже был полноэкранным, возврат к раскладке не выводит весь браузер из этого режима.

Проверки охватывают светлую и тёмную темы, обычный режим и инкогнито, пустую панель, закрытие панели и Escape внутри страницы ИИ. Само разворачивание — временное состояние, не новая сохранённая раскладка.

Обновление из 6.0.13: в обычном режиме «Обновить» → «Скачать обновление» → «Установить и перезапустить». Удалять приложение и профиль не требуется.

Маскот, иконка Dock, скриншоты, кошелёк и другие функции не изменялись. Предварительная сборка для Mac Apple Silicon с ad-hoc подписью, без Developer ID и нотариализации Apple.
