# Mouse Browser 6.0.35

Черновик отложенного выпуска. По решению владельца сейчас публикуется только macOS; данный пакет и канал6.0.35 не выпускаются.
## Что изменилось

- **Агент Маус стал чатом.** Сообщения пользователя справа, ответы агента слева, потоковая выдача, остановка ответа и удобные блоки кода. История разговора хранится в текущем сеансе отдельно для каждого стола. Для обычного общения достаточно настроить модель.
- **Настройки агента вынесены в отдельное окно.** Адрес API, модель, папка проекта, разрешения, автономность и терминал открываются через шестерёнку. Технические подробности свёрнуты; разрешения запрашиваются в переписке.
- **Исправлена иконка агента:** добавлен лоб по рисунку владельца во всех пяти цветовых вариантах.
- **Переставлены кнопки:** очки инкогнито сверху слева, скриншот сразу после загрузок, смена темы непосредственно перед настройками.
- **Новое меню «Окна».** Системный стиль, наглядные схемы и отметка текущего расположения на выбранном столе. Ручные пропорции показываются как своя раскладка.
- **Закрепление окна.** Правый клик → «Закрепить окно» фиксирует место в раскладке, пропорции и привязанную вкладку. Остальная свободная часть стола остаётся доступной для работы. Открепление — через то же меню или значок булавки.
- **Списки файлов перестали сдвигаться при загрузке миниатюр.** Сохраняются прокрутка, выделение и фокус; на Linux отображается реальный предпросмотр изображений.
- **Выбранный поисковик, своя плиточная лента.** Mouse использует общую настройку Google, Bing, DuckDuckGo или Яндекса и показывает реальные результаты в собственном интерфейсе. Ключи поискового API не требуются. При ручной проверке поисковика можно открыть его настоящую страницу; исходный запрос сохраняется.

## Проверка выпуска

Публикуются те же установочные файлы, которые проходят проверки установленного приложения, обновления с сохранением профиля, реального поиска и независимую проверку SHA-256. Источники изменений и доказательства: [исходники PR187](https://github.com/jeep-jim/OSMINOG/pull/187), [выпуск PR63](https://github.com/jeep-jim/OSMINOG-Releases/pull/63).

Проверка чата использует отдельный HTTP/SSE сервер в тестовом окружении. Для разговора с вашей моделью укажите её адрес API и название в настройках агента. Подключение к личному Ollama владельца удалённо не проверялось.
