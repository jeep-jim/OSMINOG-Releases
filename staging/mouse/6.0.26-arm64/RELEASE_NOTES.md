# Mouse Browser 6.0.26 — Нора и полная палитра

Версия для macOS Apple Silicon с обновлённым раскрытием «Норы» и полной
палитрой редактора скриншотов.

## Изменения

- «Нора» плавно вырастает из нижней панели и втягивается обратно единым
  соединённым контуром.
- Меню и элементы выровнены относительно общей центральной оси.
- Повторное открытие, прерывание анимации и изменение размеров сохраняют
  соединение с нижней панелью. Учитывается системное уменьшение движения.
- В редакторе скриншотов возвращён выбор произвольного цвета: цветовое поле,
  оттенок и точный ввод HEX. Цвет применяется к разметке и сохраняется в PNG.

## Установка

В установленном Mouse Browser нажмите номер версии в нижней панели,
затем «Скачать обновление» → «Установить и перезапустить».
Для ручной установки используйте DMG из файлов этого выпуска.

Подпись macOS остаётся ad-hoc; Developer ID и нотариализация не заявляются.
