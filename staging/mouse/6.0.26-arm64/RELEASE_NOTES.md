# Mouse Browser 6.0.26 — Нора и полная палитра

Версия для macOS Apple Silicon с обновлённым раскрытием «Норы» и полной
палитрой редактора скриншотов.

## Изменения

- «Нора» вырастает из нижней панели и втягивается обратно единым соединённым
  контуром. Боковые стороны симметричны, история выровнена по центральной оси.
- Повторное открытие во время закрытия продолжается от показанной формы.
  Изменение высоты сохраняет соединение с панелью; учитывается уменьшение движения.
- В редакторе скриншотов доступен произвольный цвет: цветовое поле, оттенок и HEX.
  Цвет применяется к существующей разметке и сохраняется в PNG.
- Область перетаскивания окна сохранена; ширина вкладок учитывает занятое ею место.

## Установка

В установленном Mouse Browser нажмите номер версии в нижней панели,
затем «Скачать обновление» → «Установить и перезапустить».
Для ручной установки используйте DMG из файлов этого выпуска.

Подпись macOS остаётся ad-hoc; Developer ID и нотариализация не заявляются.
