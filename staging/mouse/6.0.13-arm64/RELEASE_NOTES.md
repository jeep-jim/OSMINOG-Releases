# Mouse Browser 6.0.13 — вкладки и полный снимок экрана

Для Mac Apple Silicon / M1 Pro. Обновление из 6.0.12 через обычный режим: «Обновить» → «Скачать обновление» → «Установить и перезапустить». Удалять приложение или профиль не требуется.

Верхние вкладки сжимаются в одну строку; плюс остаётся после последней вкладки. Перетаскивание верхней вкладки на другую меняет их местами. Панели можно менять местами за значок сайта/свободную часть их верхней строки: страницы и открытые сессии остаются прежними, без перезагрузки. Отмена перетаскивания возвращает исходную раскладку.

Повторяющееся название страницы из строки каждой панели убрано; адрес начинается сразу после значка сайта. При редактировании адрес занимает всю ширину строки, а после завершения возвращаются кнопки. Escape отменяет редактирование адреса.

Верхняя строка ИИ выровнена по высоте с другими панелями. Значки компактнее, стрелка списка отодвинута от правого края, выбранный сервис отмечается галочкой. История, закладки и загрузки перемещены в правую группу перед кнопкой ИИ. Постоянная надпись «Mouse Browser готов» убрана. В настройках добавлен домен mouse.black; сайт или DNS этим выпуском не развёртываются.

Кнопка камеры и Control+A используют общий захват выбранного монитора, а не области браузера. Предпросмотр помещает весь кадр по ширине и высоте, сохраняя исходные пиксели для PNG. Для нативного захвата явно включено системное меню и перечисление окон рабочего стола; после выбора экрана дана короткая пауза на закрытие системной плашки. Разрешение macOS по-прежнему необходимо. Снимается выбранный монитор и видимое содержимое; скрытые самой macOS Dock и меню не дорисовываются, разрешения не обходятся.

Проверки перед публикацией: прежние приватность/профиль/закрытие/захват и восстановление интерфейса, реальные перетаскивания и сохранение порядка, размещение более двадцати вкладок, обе темы, полный кадр 3456×2234 с проверкой всех краёв и сохранённых пикселей, настоящее получение изображения монитора двумя разрешёнными способами. Отдельно проверяются установка из DMG и переход 6.0.12→6.0.13 с сохранением профиля.

Сборка предварительная, ad-hoc, без Developer ID и нотариализации Apple. Профиль `~/Library/Application Support/Trader OS` не удалять. Личный Mac владельца удалённо не проверен; неизвестные причины прежнего системного вылета не объявляются устранёнными. Кошелёк остаётся экспериментальным, sepolia-only, неаудированным. Другие платформы и АвтоЦена не публикуются.
