# Mouse Browser 6.0.45

Подготовка выпуска для macOS arm64. Этот файл не означает, что выпуск опубликован.

В версии подготовлены Mouse ID с именем и аватаром, защищённые системой учётные данные и отдельные профили пользователей. Синхронизация переносит лёгкие настройки рабочего пространства: сетки, закладки, темы и настройки интерфейса. Файлы, локальные архивы и содержимое страниц в эту синхронизацию не входят. После выхода открывается новая гостевая сессия.

Флэш открывается кнопкой с молнией в правой боковой панели. Сервер знакомит устройства; полезные данные идут напрямую между ними. В этой версии действует ограничение 100 GB на одну передачу. Прямое соединение зависит от сетей обоих устройств: реле TURN и обещания соединиться из любой сети нет. Сессия предполагает явное подтверждение получателем.

Название установленного приложения в интерфейсе Finder — Mouse. Текущая версия и проверка обновлений находятся в настройках; нижняя кнопка появляется при наличии обновления.

Перед публикацией требуются независимая проверка точных исходных артефактов, повторный запуск всех сохранённых и новых проверок установленного DMG, проверка обновления с 6.0.29 и 6.0.44 и доступность собственного HTTPS/STUN сервиса. Проверка на двух физических домашних Mac остаётся отдельной пользовательской проверкой; CI с двумя логическими устройствами её не подменяет.

Windows и Linux в этом выпуске не обновляются.
