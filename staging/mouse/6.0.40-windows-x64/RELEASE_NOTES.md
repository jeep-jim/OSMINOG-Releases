# Mouse Browser 6.0.40

## Настройки

Настройки разделены на девять понятных разделов: обзор, оформление, рабочие столы,
приватность, перенос данных, снимки, загрузки, документы и сведения о браузере.
Цветные векторные значки помогают различать разделы. Тёмная тема использует тёмное
стекло, светлая — светлое, с отдельными группами параметров и читаемыми подписями.

На первом экране видно состояние блокировки рекламы и её переключатель. Поиск
показывает подходящие параметры из всех разделов; очистка поиска возвращает
выбранный раздел. Узкая панель сохраняет доступ к навигации и настройкам.

Настройки применяются к прежнему профилю. Блокировка рекламы сохраняет ваш выбор;
сам редизайн не включает её автоматически. Поддерживаемые сетевые фильтры
EasyList и RU AdList остаются прежними. Полное удаление рекламы внутри каждого
видеопотока не заявляется.

## Settings

Settings now has nine clear sections: overview, appearance, workspaces, privacy,
data transfer, captures, downloads, documents and browser information. Colored
vector icons distinguish the sections. Dark and light glass surfaces separate
setting groups with readable labels in both themes.

The first screen exposes the ad blocking status and switch. Search finds
settings across sections; clearing it returns to the selected section. A narrow
panel keeps navigation and controls accessible.

Your existing profile and saved choices are retained. This redesign does not
automatically enable ad blocking. Supported EasyList and RU AdList network
filters are unchanged; complete removal of ads embedded in every video stream
is not claimed.
