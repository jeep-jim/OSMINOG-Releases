# Mouse Browser 6.0.32 — Windows x64

## Изменения

- Убраны повторные изменения элементов соседних панелей и повторное монтирование их содержимого при смене музыкального заголовка. Нативная проверка локального проигрывателя контролирует сохранность страниц, ввода и размеров.
- Скрыты нативные горизонтальные и вертикальные полосы прокрутки. Прокрутка колесом, клавиатурой и жестами остаётся доступна, включая вложенные области, iframe и shadow DOM.
- Нижняя панель переставлена по согласованному макету: ровные размеры иконок, аккуратные отступы и промежутки между группами. Логотип предлагает открыть mouse.black; настройки доступны из Норы.
- Помощник доступен по желанию через настройки: убраны стартовая реклама и автоматическое открытие панели.
- Логотип Windows сохраняет правильные пропорции 19×17 и сглаживание при масштабировании. Иконка установщика и ярлыка содержит отдельные изображения для десяти размеров, включая 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей.
- Встроенные документы открываются для просмотра. Редактирование файлов в Mouse Browser отключено.

## Проверка выпуска

Публикуются только точные байты успешной сборки с нативными проверками, повторно установленной и проверенной в отдельном Windows-окружении. Проверки включают установку и обновление, сохранение профиля, фоновые задачи и 50 живых вкладок на пяти столах, переключение треков без изменения размещения, скрытые полосы с реальными событиями прокрутки и режим просмотра документов.

Физический компьютер владельца и сторонние аккаунты не проверялись. Визуальная проверка реального пакета выполняется на Windows runners; она не подтверждает поведение каждого драйвера и масштаба экрана.

## Установка и обновление

Самостоятельный NSIS-установщик; отдельные Node.js, Python и npm пользователю не нужны. Сохраняются идентификатор приложения и существующий профиль Windows. Переход с опубликованной 6.0.29 проверяется старым приложением, заменой через NSIS и чтением профиля новой версией. Отдельно проверяется встроенное обновление и повторный запуск. Установщик и приложение распространяются без цифровой подписи.
