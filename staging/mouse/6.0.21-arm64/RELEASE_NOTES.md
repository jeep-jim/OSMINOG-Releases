# Mouse Browser 6.0.21 — рабочие столы и удобное перетаскивание

## Рабочие столы

Норка находится строго по центру нижней панели и открывает полупрозрачную панель столов. Рядом с вкладками снова обычный постоянно видимый «+» для новой вкладки. При первом переходе создаются пять столов; существующие вкладки и раскладка сохраняются в центральном, третьем столе. Столы имеют отдельные вкладки, раскладки и ИИ-панель. Можно добавлять и переименовывать столы. Это рабочие пространства внутри одного приложения, не отдельные процессы/аккаунты/профили.

Переключение имеет плавную направленную анимацию без перезагрузки и изменения размеров страниц. Настройка ОС уменьшения движения учитывается. Страницы скрытых столов остаются живыми и продолжают потреблять ресурсы. Счётчик показывает числовое число непрочитанных, которое сам сайт помещает в заголовок вкладки; это не универсальный доступ к содержимому всех мессенджеров.

## Управление и перенос

Системные сообщения больше не занимают нижнюю панель постоянно: временное сообщение показывается по центру снизу и исчезает. Повтор того же сообщения не продлевает его бесконечно.

При перетаскивании вкладки/окна подсвечивается целевая рамка, возле указателя виден небольшой предпросмотр. Для изображений добавлен нативный перенос PNG между страницами по настоящему действию мышью. Принимающий сайт должен поддерживать загрузку файлов перетаскиванием; отправка сообщения остаётся действием пользователя. Произвольный код сайтов не получает доступ к локальным путям или скрытым/приватным вкладкам другого пространства.

«Т+» возле смайлика управляет масштабом страниц на всех столах, включая новые вкладки. После чисел в библиотеке указано название раздела. Редактор снимков имеет выделение/перемещение объектов мышью и стрелками клавиатуры, Shift для увеличенного шага, отмену/повтор. Исходный цвет инструментов зелёный; палитра закрывается повторным нажатием и выбором цвета.

## Инкогнито и сохранность

Прежний приватный маскот и фиолетовые очки восстановлены из6.0.19; сохранён новый ровный пиксельный заголовок рядом с маскотом. Иконка обычного приложения/Dock остаётся утверждённой мордочкой без хвоста. Основные круглые кнопки и12px скругления окон сохранены.

Приватные столы и данные отделены от обычных и не сохраняются в обычный профиль. Локальный автосбор снимков/текста сохраняет прежние правила: выключен по умолчанию, отдельное согласие, пауза в инкогнито/при блокировке, без сетевой отправки. Профиль и оригинальные файлы не удаляются.

## Установка

Обычный режим: «Обновить» → «Скачать обновление» → «Установить и перезапустить». Предварительная сборка macOS Apple Silicon (arm64), подпись ad-hoc, без Developer ID и нотариализации Apple. Windows и другие продукты не публикуются. Проверки на сборочной машине не заменяют проверку всех сайтов на личном Mac.
