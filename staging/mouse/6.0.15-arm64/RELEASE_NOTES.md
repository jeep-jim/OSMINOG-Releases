# МАУС · Mouse Browser 6.0.15

Проект Mouse Browser, домен mouse.black. Для macOS Apple Silicon, включая M1 Pro.

Сама кнопка новой вкладки теперь имеет форму мышиной норки — без дополнительной квадратной подложки. Внутри маленькая голова исходного маскота. При наведении она исчезает, при уходе указателя возвращается. Нет нижней светящейся полосы, свечения или тени. Кнопка остаётся возле последней вкладки; действие новой вкладки и ⌘T сохранены. Цвета учитывают светлую и тёмную темы; при уменьшении движения в системе анимация отключается.

История, закладки и загрузки собраны отдельной компактной группой левее блока ИИ / кошелька / обновления, с промежутком по отметке владельца. При узком окне промежуток уменьшается. Это прежние кнопки с теми же обработчиками, без дублирования функций.

Другие части интерфейса не переделаны. Изображения маскота, фиолетовые очки и постоянная иконка Dock сохранены. Полноэкранный ИИ и зелёная рамка подтверждённого обновления из 6.0.14 сохранены. Код захвата экрана, кошелька, защиты и рабочие данные не изменены.

Обновление из 6.0.14 в обычном режиме: «Обновить» → «Скачать обновление» → «Установить и перезапустить». Профиль и установленное приложение заранее не удалять.

Предварительная сборка с ad-hoc подписью, без Developer ID и нотариализации Apple. Исторические технические адреса канала и ключи данных сохранены для совместимости. Другие платформы, АвтоЦена, DNS и хостинг не публикуются и не меняются.
