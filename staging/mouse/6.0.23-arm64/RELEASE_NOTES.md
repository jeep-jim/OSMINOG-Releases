# Mouse Browser 6.0.23 — форма норки и вкладки

## Что изменилось

- Верхний изгиб норки одинаков в трёх состояниях: обычном, с раскрытыми режимами и с превью стола.
- Панель соединяется с футером без горизонтальной линии внутри основания. Цвет внешнего контура совпадает с верхней границей футера в светлой и тёмной темах.
- Окна в сетке и открытые фоновые вкладки учитываются отдельно. Закрытие окна закрывает соответствующую страницу; закрытые вкладки исчезают из счётчиков и превью. Уже открытые фоновые вкладки сохраняются.
- Плашки вкладок показывают иконки сайтов. Их можно переставлять, переносить на другой стол и закрывать; длинный список прокручивается горизонтально.
- Обновления заголовков сохраняют существующие плашки и элементы превью. Повторные запросы снимков используют общий кратковременный кеш, уменьшая лишнюю работу интерфейса.
- Agent Mouse доступен в стартовом выборе помощника и списке ИИ. Его обозначает цветной пиксельный мышонок с антенками; агент остаётся выключенным до явного включения.

Сохранены пять столов, раскладки, превью, существующие вкладки и Agent Mouse из 6.0.22. Перестановка вкладок сохраняет порядок вкладок ИИ.

## Проверка

В установленной macOS arm64-сборке проверены три состояния норки в обеих темах, реальные закрытия и перетаскивания вкладок, сохранение страниц, иконки, устойчивость элементов при обновлении заголовков и оба входа Agent Mouse. Повторены прежние проверки браузера и Agent Mouse, включая локальную модельную fixture, CDP, PTY, автономные действия и Stop. Проверено реальное обновление 6.0.22 → 6.0.23 с сохранением профиля. Процентное снижение CPU или памяти не заявляется.

Обновление в обычном режиме браузера: «Обновить» → «Скачать обновление» → «Установить и перезапустить».

Сборка для macOS Apple Silicon (arm64), с подписью ad-hoc, без Developer ID и нотариализации Apple.
