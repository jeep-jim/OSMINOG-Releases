# Mouse Browser 6.0.29 — Windows x64

Установщик самостоятельного Mouse Browser для 64-разрядной Windows. Это версия
6.0.29 с исправлениями цвета разделителей, отображения Норы поверх
страниц и прокрутки колёсиком внутри Норы.

## Установка

Скачайте `Mouse-Browser-6.0.29-Windows-x64.exe` и запустите мастер установки.
Требуется Windows 10 версии 1903 (сборка 18362) или новее, либо Windows 11,
64-разрядная система. Программа устанавливается для текущего пользователя.
Node.js, npm и Python отдельно устанавливать не нужно.

## Адаптация для Windows

- Системные кнопки свернуть, развернуть и закрыть окно; сочетания с Ctrl.
- `Ctrl+A` выделяет всё, `Ctrl+Alt+S` запускает захват экрана.
- Панели страниц, столы, документы, приватное окно и локальные папки.
- Локальный агент использует Windows PowerShell и ConPTY; разрешения на папку,
  запись и команды выбираются в интерфейсе.
- Отдельный канал обновлений Windows, проверка SHA-256 установщика и повторный
  запуск приложения после установки.

Профиль Windows хранится в `%APPDATA%\Mouse Browser`. Удаление программы не
удаляет профиль. Обычная установка и переустановка не требуют ручного переноса
этих данных.

## Проверка и границы

Этот выпуск публикуется только после установки точного файла на Windows,
проверки нативного интерфейса, локального агента и терминала, сохранения профиля
после перезапуска и переустановки, а также фактической замены и перезапуска через
кнопки обновления. Независимый выпускной прогон повторно проверяет тот же файл
на другой Windows-машине CI. Затем публичный установщик целиком скачивается
анонимно с проверкой размера и SHA-256.

Проверка замены использует эту же версию и локальный поток проверенного
установщика; она не заявляет миграцию с ранее опубликованной Windows-версии
Mouse. Публичный канал и загрузка проверяются отдельно. Ввод мыши и клавиатуры
в CI настоящий системный, но программно сгенерированный; физический тачпад и
компьютер владельца этим не проверены.

Сборка распространяется как prerelease без цифровой подписи издателя.
Windows может показать предупреждение SmartScreen. Фактический статус подписи
сохранён в отчёте проверки. SHA-256 находится в `SHA256SUMS.txt`; исходник,
проверочные запуски и контрольная сумма приведены ниже.

Исходник этой версии закреплён в отдельной ветке `release/mouse-6.0.29`.
Основная ветка проекта с более новыми изменениями сохранена: этот выпуск
не откатывает и не заменяет её. Публикация требует успешной проверки точного
исходника и его слияния именно в ветку версии 6.0.29.
