# Mouse Browser 6.0.28 — Нора, прогресс и Локал

## Что изменилось

- **Прогресс у каждой панели.** Задача привязана к своей вкладке и отображается пилюлей под соответствующей панелью. Показываются известный процент и процесс без числа; завершение и остановка обновляют состояние. Обычная загрузка страницы наблюдается отдельно. Сайт может передавать собственный прогресс через API, если он его предоставляет.
- **Локальные файлы для помощника.** Разрешённую папку можно открыть и просмотреть дерево файлов. Чтение, поиск и запись работают через локальный MCP сервер с отдельным разрешением на изменения. Сохраняется журнал действий; для локальной разработки можно перезапустить управляемый процесс. Доступ ограничен выбранной папкой и отзывается при остановке. Проверка использовала локальную модель-заглушку; совместимость с конкретной внешней моделью этим не подтверждается.
- **Нора и панели.** Убраны полосы и декоративные обводки, включая маленькую Нору, в светлой и тёмной темах. Содержимое Норы помещается в панель без внутренней прокрутки; открытие и закрытие сопровождаются сдвигом. Переключение рабочего стола при открытой Норе сохраняет её состояние и живые страницы.
- **Знакомство с жестом.** При первом использовании показывается подсказка о переключении столов тремя пальцами; успешное действие скрывает её, состояние сохраняется после перезапуска. Проверена обработка события в установленном приложении через программный нативный ввод; физический трекпад в CI не проверялся.

Сохранены документы в обычных вкладках, произвольная палитра снимков и профиль пользователя из 6.0.27. Выпуск предназначен для macOS Apple Silicon (arm64). Пакет имеет подпись ad-hoc; Developer ID и нотариализации Apple нет.

## Проверка

Публикация привязана к точному коммиту исходника и DMG/ZIP из прошедшего Mac-прогона. Перед размещением файлов повторно проверяются установленное приложение, изображения и сохранённый профиль, а также реальная замена публичной 6.0.27 на 6.0.28. Затем прежний обновлятор 6.0.27 должен найти канал и целиком скачать пакет с проверкой SHA-256. Измеренные промежуточные кадры и трасса подтверждают проверенные переходы; одинаковая плавность на каждом устройстве не заявляется.
