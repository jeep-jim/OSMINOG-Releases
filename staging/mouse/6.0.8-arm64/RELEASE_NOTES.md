# Mouse Browser 6.0.8 — окна, скриншоты и обновление

Выпуск для Mac Apple Silicon, включая M1 Pro. Имя и исходный маскот Mouse Browser сохранены. Профиль `~/Library/Application Support/Trader OS`, cookie и обычные вкладки не переименовываются и не удаляются.

## Пять исправлений владельца

**Инкогнито:** мышь белая, очки чёрные с прежними белыми пиксельными бликами. Хвост влево. Исходная маска масштабируется равномерно, каждая клетка и отдельная точка усов квадратная 2x2, без растягивания по разным осям. Обычная иконка без очков.

**Dock:** всегда чёрная мышь на белой подложке, независимо от системной темы и темы браузера.

**Полный экран отдельной панели:** в строке каждого окна есть кнопка разворачивания выбранной панели. Дерево раскладки и размеры остальных окон не перезаписываются. Выход возвращает панель в прежнее место; страницы не перезагружаются. Учитывается, был ли сам браузер уже в полном экране. При переходе в инкогнито временный режим разворачивания сбрасывается.

**Скриншот всего Mac:** добавлен нативный одноразовый захват ScreenCaptureKit. На macOS 14+ есть системный выбор экрана с явным разрешением пользователя, когда общее разрешение записи экрана недоступно. Старый путь macOS 13 сохранён. Control+A работает, пока браузер запущен; Cmd+A остаётся выделением. Камера браузера сохраняет отдельный режим снимка его окон. Нет фоновой записи, аудио, загрузки кадров в облако или обхода системного отказа. При успехе открывается прежний редактор с разметкой. На CI проверен настоящий захват при уже выданном разрешении; выбор/согласие на личном M1 Pro и конкретная причина его прежнего отказа не объявляются проверенными.

**Обновление из приложения:** основной канал — небольшой статический HTTPS-файл, GitHub API только резерв. Проверяются адрес, версия, архитектура, размер и SHA-256. Новая кнопка установки подготавливает приложение, сохраняет текущую сессию, заменяет его и запускает снова без обычного ручного переноса из DMG. Старое приложение сохраняется рядом в служебном каталоге для восстановления. Нужны права записи в каталог приложения; повышения привилегий и отключения защиты нет.

## Однократный переход с 6.0.7

В установленной 6.0.7 нового обновлятора ещё нет, поэтому её HTTP403 нельзя исправить одной публикацией на сервере. Для перехода скачайте этот DMG, завершите браузер через Cmd+Q, скопируйте Mouse Browser.app в «Программы» с заменой и запустите оттуда. После перехода на6.0.8 последующие выпуски поддерживают новый механизм «Установить и перезапустить». Работа нового механизма проверяется настоящей заменой тестовой6.0.7 на6.0.8 НОВЫМ установщиком и сохранением профиля; это не тест старой кнопки6.0.7.

Не удаляйте `~/Library/Application Support/Trader OS`. Не запускайте Quadro и Mouse одновременно. Quadro-Browser-6.0.8-mac-arm64.dmg — побайтовый совместимый псевдоним основного Mouse DMG для старого поиска выпусков, не отдельный продукт.

## Границы

Сборка предварительная, подпись ad-hoc, без Developer ID и нотариализации Apple. macOS может потребовать отдельного подтверждения запуска и разрешения записи экрана; updater их не обходит. Нет sudo/xattr/spctl/tccutil/defaults. Разрешение запускать приложение и разрешение захвата экрана — разные механизмы.

Фавиконки во всех списках (issue138) и лишняя нативная полоса раскрытия системного меню не исправляются этим выпуском. Кошелёк остаётся только тестовой Sepolia, без независимого аудита и не для настоящих средств. Инкогнито не обещает анонимности, очистки системных журналов/RAM/swap; явно сохранённые файлы и буфер обмена остаются.

Проверки исходного приложения выполнены на Mac Apple Silicon, повторная проверка запускается из фактического DMG до публикации. Проверка доступности нового публичного канала выполняется отдельным шагом после публикации; её результат не подменяется синтетическим тестом. Физический Mac владельца не проверен удалённо. Другие платформы и АвтоЦена не публикуются.
