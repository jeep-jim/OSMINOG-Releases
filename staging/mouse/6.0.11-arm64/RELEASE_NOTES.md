# Mouse Browser 6.0.11 — светлая тема инкогнито

Mac Apple Silicon / M1 Pro.

В инкогнито светлая тема теперь использует светло-серый фон и чёрную мышь. Иконки внутренней вкладки и строки панели также чёрные с фиолетовыми очками. В тёмной теме сохраняются тёмный фон и белая мышь. При переключении темы уже открытые изображения меняются сразу; новые вкладки получают правильный вариант.

Фиолетовые очки #A855F7, белые блики, исходные контуры, квадратные усы и хвост не перерисованы и не инвертируются. Dock остаётся чёрной мышью на белом фоне. Остальные функции, хранение приватной сессии, захват, системное меню и кошелёк не изменялись.

Обновление из 6.0.10: в обычном режиме «Обновить» → «Скачать обновление» → «Установить и перезапустить». Удалять приложение или профиль `~/Library/Application Support/Trader OS` не требуется.

Предварительная сборка с ad-hoc подписью, без Developer ID и нотариализации Apple. Защита macOS не отключается. Установка на личном Mac пользователя удалённо не выполнялась.
