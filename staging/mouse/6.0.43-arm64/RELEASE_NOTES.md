# Mouse Browser 6.0.43 for Mac

## Search and navigation

- The Mouse mark on an ordinary new tab stays black in both themes.
- The search field has a leading provider icon and selectable, keyboard-accessible suggestions in a blurred dropdown.
- An expanded page address has a copy button at the right. The chevron beside its favicon opens a list of existing pages across all workspaces and recent history, with favicons.
- Selecting an already open page activates its existing tab and workspace.

## Mac interface

- The active top tab uses the underlying theme surface. Square workspace mode also has square top tabs.
- Tab paint and widths stay stable as page titles change. Split guides stay within their one-pixel seam in square mode.
- Custom panel colors preserve the Mac window controls, the burrow and compact page controls.
- Settings uses flatter sections and inset dropdown chevrons.

## Website themes and retained data

The browser applies its saved native color preference before restoring pages,
waits for live theme changes, and restores the normal preference when leaving
private browsing. A website's explicit theme choice can still take precedence.
Search suggestions are disabled in private browsing.

Existing workspaces, tabs, profile identity, input-language controls and
consent-based keyboard-layout correction are retained. Native acceptance covers
installation and updates from published 6.0.42 and legacy 6.0.29, real pointer
actions, page identity, restart, and independent checks of actual display pixels.

This release is for Mac Apple Silicon. Windows and Linux remain on 6.0.42 until
development for those platforms is explicitly resumed. The Mac package remains
an ad-hoc signed preview without Apple Developer ID notarization.
