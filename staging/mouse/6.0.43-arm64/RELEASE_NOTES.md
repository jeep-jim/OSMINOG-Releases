# Mouse Browser 6.0.43 for Mac

This candidate refines Mac tabs, square workspace separators and Settings;
preserves traffic-light and Nora shapes with custom panel colors; and adds
search suggestions and clearer address copy/page-selection controls. Ordinary
pages follow the browser's selected color preference.

Existing tabs, workspaces, profile data, input-language controls, consent-based
text correction and update channels are retained. Acceptance requires native
actions and independent raw-image/process verification, including update from
published 6.0.42 and legacy 6.0.29.

Mac Apple Silicon preview with ad-hoc signing; no Developer ID notarization is
claimed. This candidate is not published until its exact native and public gates
complete. Linux and Windows 6.0.43 are outside this publication.
