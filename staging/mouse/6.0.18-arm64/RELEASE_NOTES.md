# Mouse Browser6.0.18 — норка ниже и компактнее

Точечная правка после6.0.17: основание кнопки новой вкладки опущено на1px до нижней границы серой разделительной полосы; высота уменьшена на3px — с32 до29px. Ширина36px, исходные линии, градиент и серый плюс12px с появлением при наведении/клавиатурном фокусе сохранены. Логотипы, нижняя панель и прочий интерфейс не переделаны.

Проверки сравнивают новую геометрию с6.0.17 в обеих темах, проверяют клики и обновление6.0.17→6.0.18 с сохранением профиля. Публикуются только точные проверенные пакеты, с повторной проверкой установки из DMG.

Обновление в обычном режиме: «Обновить» → «Скачать обновление» → «Установить и перезапустить». Профиль `~/Library/Application Support/Trader OS` не удалять.

Предварительная сборка macOS Apple Silicon, подпись ad-hoc, без Developer ID и нотариализации Apple. Защита macOS не отключается; прежние выпуски не перезаписываются. Проверка на сборочной машине не является проверкой личного Mac пользователя. АвтоЦена, DNS и выпуски других платформ не изменены.
