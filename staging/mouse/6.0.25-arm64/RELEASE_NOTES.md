# Mouse Browser 6.0.25 — документы и выбор поиска

Запрошенные изменения; установленная сборка ещё должна пройти проверку перед публикацией:

- Открытие PDF, DOCX, XLSX и UTF-8 текстовых файлов в редакторе Mouse через «Документы» или ⌘O, с сохранением пользовательской сетки браузера.
- PDF: просмотр, текстовые пометки, маркер, перо и поворот страниц. Исходный текст не редактируется и не удаляется; OCR и защищённое удаление содержимого не входят в эту версию.
- Word: правки поддерживаемых текстовых фрагментов и полужирного/курсивного оформления с сохранением других частей DOCX. Сложная вёрстка может отображаться упрощённо.
- Excel: правка значений и обычных формул, базовые форматы и ограниченный пересчёт. Неподдерживаемые формулы сохраняются, их старые результаты помечаются; полного вычислителя Excel нет.
- «Сохранить копию» и «Сохранить как…» через системный диалог, проверка внешних изменений файла, выбор при несохранённых правках и очистка открытых документов при переходе приватности. Явно сохранённый файл остаётся на Mac.
- Google по умолчанию на чистом профиле; рядом с поиском новой вкладки — компактный выбор Google, Bing, DuckDuckGo или Яндекса с видимым текущим названием. Поиск с новой вкладки и адресная строка используют одну настройку, сохранённый выбор пользователя сохраняется.
- Инкогнито наследует обычную настройку поиска при входе. Выбор внутри приватного режима действует в памяти до выхода; при следующем входе снова применяется обычная настройка.

Выпуск объединяет ранее подготовленные изменения 6.0.24 и новые функции 6.0.25 в одно обновление с опубликованной 6.0.23. Промежуточная установка 6.0.24 не требуется. Сохранены Agent Mouse без перестройки пользовательской сетки, история изменений раскладки и индикаторы прогресса с обозначением оценочных процентов ИИ.

UNSET_VERIFICATION: финальный исходник и merged PR, успешный native run, точные candidate/verification archives, установленный результат, три скриншота документов, два скриншота выбора поиска, отчёты документов/поиска и реальное обновление опубликованной 6.0.23 → 6.0.25 с сохранением профиля ещё не закреплены. Существующий пакет 6.0.23 и её настоящий updater привязаны к проверенным SHA; их повторная проверка остаётся обязательной частью выпуска. Все прежние проверки браузера и Agent Mouse сохраняются. Публикация использует проверенные DMG/ZIP без повторной сборки.

Сборка для macOS Apple Silicon (arm64), с подписью ad-hoc, без Developer ID и нотариализации Apple.
