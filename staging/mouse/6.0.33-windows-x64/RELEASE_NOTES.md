# Mouse Browser 6.0.33

Восстановлен Агент Маус. Правая кнопка панели открывает настройки.
Масштаб страницы применяется при движении ползунка.
Стрелка загрузок показывает прогресс, подпрыгивает после завершения
и сохраняет счётчик новых файлов до открытия загрузок.
В настройках доступны импорт выбранных файлов закладок и паролей,
а также подсказки по установке Ollama. Пароли хранятся с шифрованием ОС
и копируются по нажатию; автоматическое заполнение пока не добавлено.
Сохранены исправления переключения музыки, скрытые полосы прокрутки
и просмотр документов.

Контекстное меню добавляет текущую страницу в избранное, разделяет панель
справа или снизу и предлагает сетки окон с иконками.
Крестик закрытия панели убран из нижней строки.
