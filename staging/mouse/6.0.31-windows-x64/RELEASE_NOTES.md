# Mouse Browser 6.0.31 — Windows x64

## Изменения

- Плашка больше не появляется от обычной загрузки страницы. Она относится к явно сообщённой фоновой задаче сайта или агента.
- Сайт может передать процент, этап и оценку оставшегося времени через `window.MouseAgent.updateProgress`, совместимый `browser.setProgress` или разметку `data-mouse-task`. Из переданной оценки идёт отсчёт; истёкшая оценка не означает готовый ответ. Без оценки показано прошедшее время. Завершённая задача сразу убирается.
- Обычные сайты без такой интеграции не получают придуманные проценты или сроки. Браузер не читает текст переписки для угадывания времени ответа.
- Уменьшена повторная работа при обновлении заголовков, фоновых вкладок и переключении столов. Миниатюры ограничены 16 MiB. Живые страницы, формы, прокрутка и фоновые процессы сохраняются; принудительная перезагрузка вкладок не используется.
- При переключении стола место под плашку готовится до размещения страницы. Это устраняет повторное изменение высоты страницы и появление её старого фрагмента поверх плашки. Если система захвата возвращает кадр прежнего размера, браузер отбрасывает его и запрашивает свежий в пределах существующего времени перехода.
- Исправлено обновление размера скрытой страницы перед переходом: движок получает новый размер той же вкладки, при этом она остаётся скрытой, а её документ, введённые данные и фоновые соединения сохраняются.
- В невысоких окнах раскрытая справка Норы использует компактный предпросмотр стола, чтобы полностью помещаться по высоте. Размеры текста и кнопок сохранены.
- Сохранены согласованные правки: плашка под адресной строкой своей панели, реальный прогресс скачивания, подтверждение снимка, цвета разделителей, Нора поверх страниц, скругления и внутреннее переключение двумя пальцами/колесом.

## Подключение сайта

```javascript
await window.MouseAgent.updateProgress(35, 'Формирую ответ', {
  taskId: 'answer-1', phase: 'running', etaSeconds: 45
});
// Когда ответ действительно готов:
await window.MouseAgent.updateProgress(100, 'Ответ готов', {
  taskId: 'answer-1', phase: 'completed'
});
```

`etaSeconds` необязателен. Это оценка самого сайта; браузер не вычисляет срок работы сторонней модели. Доступны состояния `running`, `completed`, `stopped`, `cancelled`, `error`. Пределы: 64 работающие задачи в браузере, не более четырёх на страницу. Интеграция не добавляет сайту доступа к другим вкладкам или данным профиля.

## Проверка выпуска

Публикация разрешается только после нативных проверок точного пакета и повторной установки перед выпуском. Отдельные сценарии проверяют обычную загрузку без плашки, жизненный цикл задач, оценку и прошедшее время, 20 и 50 живых вкладок на пяти столах, формы/прокрутку/cookies и непрерывные HTTP-потоки. Снимки настоящего экрана проверяются независимо по декодированным пикселям, геометрии и контрольным суммам.

Результат не является сравнительным benchmark с Chrome. Физический компьютер и тачпад владельца, сторонние аккаунты ChatGPT/DeepSeek не проверялись. DOOM по упомянутому сценарию в этот пакет не включён: в доступном документе DeepSeek сценария игры нет.

## Установка и обновление

Самостоятельный NSIS-установщик; отдельные Node.js, Python и npm пользователю не нужны. Сохраняются идентификатор приложения и существующий профиль Windows. Переход с опубликованной 6.0.29 проверяется настоящим старым приложением, заменой через NSIS и чтением профиля новой версией. Отдельно проверяется фактический updater и повторный запуск. Установщик и приложение распространяются без цифровой подписи.
