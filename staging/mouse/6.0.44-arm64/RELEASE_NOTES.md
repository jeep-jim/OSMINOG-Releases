# Mouse Browser 6.0.44 for Mac

## Mouse name

The installed application's visible name is Mouse. Its stable bundle identity,
profile and update-compatible filesystem paths are retained.

## Website appearance

Websites receive the selected light/dark preference. Supported built-in theme
conventions synchronize locally, including existing and private pages, and can
be disabled in Settings. Account preferences and stored site data are preserved.

## Network filters

Settings manages the bundled and custom subscriptions, conditional refresh and
per-site exceptions. The last valid local list remains available when an update
fails. The browser includes fallback lists for the enabled built-in sources.

This release is for Mac Apple Silicon only. Windows and Linux remain on 6.0.42.
It remains an ad-hoc signed preview without Apple Developer ID notarization.
