# Mouse Browser 6.0.36

**Linux · x64**

- Полностью удалён экспериментальный плиточный поиск: кнопка, панель выдачи, скрытые поисковые страницы и обработчики собственного поиска. Адресная строка продолжает открывать сайты и отправлять обычные запросы в выбранную поисковую систему.
- Настройки Agent Mouse открываются в его текущей боковой панели. Кнопка возврата открывает тот же чат с сохранённым черновиком и выделением текста. Ответ продолжает поступать при открытых настройках; там же доступна остановка.
- Обычное переключение рабочих столов использует уже открытые страницы без создания снимков и ожидания декоративной анимации. Обновления фоновых вкладок и сохранение раскладки объединяются, чтобы сократить лишнюю работу.

Номер установленной версии отображается в нижней панели: **6.0.36**.
