This template is intentionally unready. Source/run/artifact/package provenance
remains null until successful actual source CI is independently verified.
No PUBLISH_OWNER file exists. Existing632 packages and channels are unchanged.
Publication requires the merged tested source, exact archived package bytes,
fresh installed verification and independent current-owner feedback.
Linux is a first installation: previous is null; no older Linux release is claimed.

The version-specific publisher workflow and PUBLISH_OWNER are the only main-branch
push triggers. A workflow repair retries this pinned version through the same
ready-owner, immutable-source, fresh-install, public-byte and anonymous-feed
gates. No owner file is fabricated to request a retry. Windows disables Git
CRLF conversion before checkout so all accepted historical hashes remain exact.

`mouse633-reuse.py` binds the reviewed632 algorithms by SHA256 and adapts their
expected runtime/package/helper identities in code. It never rewrites evidence,
old releases or historical report filenames. The explicitly superseded Agent
entry predicates are replaced with633 home/provider/settings UI restoration;
backend enablement remains opt-in. Current633 owner and pixel checks are separate.

The contract fixtures are synthetic unit inputs. They are never candidate/native
proof and are not substituted for the source or independently installed artifacts.
