# Mouse Browser 6.0.37

## Интерфейс и внешний вид

В настройках появились два режима расположения панелей: прежний со скруглениями и расстояниями и прямоугольная сетка без зазоров. Настройка «Тон белого» регулирует основной текст тёмной темы от #A0A0A0 до #FFFFFF. По умолчанию установлен #D4D4D4; выбор сохраняется между запусками.

Объединённая сборка также включает компактные заголовки, поиск языков, локальные расширения и исправления медиавиджета. Предусмотрены проверки настоящих установленных процессов, восстановления профиля и обновления с опубликованной 6.0.36.


Нижняя страница ИИ получила изменяемую высоту, редактируемый адрес и иконку сайта. Её можно перенести в обычную панель через выбор окна или перетаскиванием заголовка; существующая страница и её состояние сохраняются.

Режимы сразу заполняются предустановленными веб-сервисами. «Поддержка» открывает четыре веб-мессенджера слева и Google Maps справа; «Трейдер» — основной график и три вспомогательных сервиса. Возвращён режим агента с отдельной областью localhost слева и фоном по теме. Повторный выбор режима сохраняет открытые страницы.

При открытии настроек или библиотеки основные страницы временно затемняются на 14%, сохраняя обработку кликов. Тёмные боковые панели используют поверхность верхней панели. Файлы открываются нажатием на содержимое, передаются в страницы настоящим перетаскиванием файла; действия, тип и время создания доступны по правой кнопке. Постоянные кнопки просмотра и повторяющиеся подписи убраны.

Диалог обновления оформлен кругом: существующий логотип и состояние находятся в центре, кнопки расположены по кольцу, закрытие выполняется отдельной круглой кнопкой. Фон при открытии сильнее затемняется. Проверка версии, проверка установщика, загрузка и установка сохраняют прежнюю логику.

## Проверки перед публикацией

Этот файл — шаблон кандидата. Публикация разрешается только после успешных исходных и независимых установочных проверок всех трёх платформ для одного точного исходного коммита. Поля происхождения, размеры и SHA-256 добавляются из проверенных артефактов; до этого ready=false. Проверки не подтверждают работу на личном устройстве, во внешнем аккаунте VK или в Chrome Web Store.
