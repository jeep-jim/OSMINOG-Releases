## Пять рабочих столов

Панель столов поднимается из нижней норки: широкая стеклянная поверхность, более округлые верхние края и плавно расширяющееся основание. Кнопки «+» и закрытия круглые. Активный стол выделен зелёным и подписан «Вы здесь».

В браузере ровно пять столов. «+» переводит на свободный существующий стол. При обновлении старые дополнительные столы объединяются с пятым с сохранением вкладок; исходная запись сохраняется для восстановления. Рабочие столы используют общий обычный профиль браузера; это не отдельные аккаунты или процессы.

Нажатие на миниатюру показывает увеличенный предпросмотр без переключения. Видны сетка, названия страниц и последнее доступное изображение открытых окон. Кнопка «Перейти» открывает выбранный стол. Предпросмотр скрытого стола использует последний видимый кадр, хранится в оперативной памяти и не перезагружает сайты ради снимка. При блокировке экрана или переходе в приватный режим кэш очищается.

Сохранено плавное направленное переключение влево/вправо без перезагрузки страниц. Настройка ОС уменьшения движения учитывается. Скрытые страницы остаются живыми и продолжают потреблять ресурсы.

## Пять режимов сетки

Ссылка «Режимы» раскрывает панель выше. Каждый режим имеет собственную иконку и миниатюру расположения окон.

| Режим | Стартовая раскладка |
| --- | --- |
| Трейдер | Пять окон: график, новости и обзоры рынков |
| Мессенджеры и поддержка | Семь окон: Telegram, Instagram, WhatsApp и WeChat слева; Google Maps, Gmail и поиск справа |
| Разработка и дизайн | Пять окон: Figma, GitHub, документация, вопросы разработки и поиск |
| Контент и соцсети | Шесть окон: редактор, YouTube Studio, соцсети и документы |
| Агенты | Три рабочих окна и панель Agent Mouse с терминалом справа |

Предложенные сервисы открываются только на действительно пустом столе. Если уже есть обычная, внутренняя или ИИ-вкладка, применяется только раскладка. Существующие страницы, их состояние и история навигации сохраняются. Список сервисов — обычные веб-адреса; авторизация и возможности конкретного сайта зависят от самого сервиса.

## Agent Mouse

Правый блок содержит задачу, журнал действий, настройки локальной или облачной модели, папку проекта, терминал и кнопку «Стоп». Пиксельная мышь показывает, где подключён агент, и анимируется при выполнении задачи.

Модель работает в отдельном Node utility process и управляет выбранным столом через локальный CDP-совместимый коннектор. Он умеет перечислять доступные вкладки, читать DOM и содержимое страниц, открывать адреса, выполнять реальные события мыши и ввод текста, получать снимок видимой страницы и запускать команды через общий встроенный терминал. Терминал использует node-pty и xterm.

Коннектор выключен по умолчанию. После включения выдаётся отдельный адрес с токеном текущей сессии на loopback-порту; по умолчанию это 9222. Обычный глобальный Chromium debugging port не открывается. Доступ ограничен выбранным обычным столом и прекращается при остановке, смене стола/режима, переходе в приватный режим или блокировке экрана. По умолчанию клики, ввод, навигация и команды агента запрашивают подтверждение. Перед подключением можно включить автономное выполнение: после отдельного системного согласия на эту сессию агент выполняет разрешённые действия на выбранном столе и команды терминала без повторного подтверждения каждого действия. «Стоп» сбрасывает автономное разрешение; следующая сессия требует нового согласия. Выбранная папка проекта не является изолированной ОС-средой.

Для работы нужна установленная локальная либо доступная облачная модель с OpenAI-совместимым chat/completions API. Адрес, имя модели и при необходимости ключ вводит владелец. Ключ хранится в памяти текущей сессии. Перед запуском отдельно подтверждается передача задаче модели содержимого прочитанных вкладок и вывода терминала; отправка снимков включается отдельно. В комплект не входят модель, подписка или API-ключ. Проверка выпуска использует локальный детерминированный API fixture и не означает проверенного подключения к личной Qwen/DeepSeek или облачному аккаунту пользователя.

«Открыть Localhost» принимает порт и открывает результат локального сервера во вкладке этого стола. Кнопка «Стоп» закрывает соединение агента, завершает его рабочий процесс и терминал.

## Сохранённые функции и установка

Сохранены обычная и приватная темы, утверждённая мордочка приложения, круглые основные элементы управления, скругления окон, перенос PNG между страницами, масштаб страниц, редактор снимков, история, библиотека, эмодзи, ИИ-панель и сохранение профиля.

Установка через обычный режим: «Обновить» → «Скачать обновление» → «Установить и перезапустить». Выпуск для macOS Apple Silicon (arm64): предварительная сборка с подписью ad-hoc, без Developer ID и нотариализации Apple. Windows и другие продукты этим выпуском не публикуются.
